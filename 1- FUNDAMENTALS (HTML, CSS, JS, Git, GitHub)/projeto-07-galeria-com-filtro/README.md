# Projeto 07 - Galeria com Filtro

## Ideia
Uma galeria de fotos com botões de filtro por categoria.

## O que foi feito
Grid responsivo com as imagens, e botões (Todos, Natureza, Cidade, Animais) que escondem ou mostram os itens da galeria dependendo da categoria escolhida, usando atributos personalizados no HTML (`data-categoria`) lidos pelo JS.

## Imagens
Usei ilustrações fictícias representando cada categoria (natureza, cidade, animais), só pra ter conteúdo real pra filtrar e mostrar a diferença visual entre elas.

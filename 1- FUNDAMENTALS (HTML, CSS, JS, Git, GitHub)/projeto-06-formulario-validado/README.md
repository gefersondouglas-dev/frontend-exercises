# Projeto 06 - Formulário com Validação

## Ideia
Um formulário de cadastro (nome, e-mail, senha, confirmar senha) com validação feita em JS.

## O que foi feito
Validação em tempo real enquanto a pessoa digita - o campo fica com borda vermelha ou verde dependendo se está certo, com mensagem de erro explicando o motivo. O e-mail é validado usando uma expressão regular, e o formulário só é "enviado" (mensagem de sucesso) quando todos os campos estão válidos.

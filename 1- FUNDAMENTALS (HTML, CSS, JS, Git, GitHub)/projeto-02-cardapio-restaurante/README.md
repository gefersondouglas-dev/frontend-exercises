# Projeto 02 - Cardápio de Restaurante

## Ideia
Montar o cardápio de um restaurante fictício, praticando HTML semântico e CSS mais estruturado.

## O que foi feito
Usei tags semânticas (`header`, `nav`, `main`, `section`, `article`) em vez de só `div`, organizei os pratos em categorias (entradas, principais, sobremesas) e usei Flexbox pra alinhar imagem e texto de cada prato. O menu de navegação fica fixo no topo ao rolar a página, e adicionei uma media query pra ajustar o layout em telas pequenas.

## Imagens
Logo do restaurante e ícones ilustrativos de cada tipo de prato, só pra dar uma cara mais completa à página sem precisar de fotos reais.

# Projeto 08 - Lista de Tarefas com localStorage

## Ideia
A mesma lista de tarefas do projeto 5, mas agora os dados não se perdem ao recarregar a página.

## O que foi feito
Continuei com adicionar, concluir e remover tarefas, mas agora salvando tudo no `localStorage` do navegador (transformando o array em texto e depois voltando pra array ao carregar a página). Também adicionei um botão pra limpar só as tarefas já concluídas.

## Imagens
Não usei, o foco era persistência de dados no navegador.

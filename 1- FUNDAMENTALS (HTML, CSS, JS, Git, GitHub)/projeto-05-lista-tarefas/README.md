# Projeto 05 - Lista de Tarefas

## Ideia
Uma lista de tarefas (to-do list) simples, sem salvar os dados ainda.

## O que foi feito
Campo pra digitar e adicionar tarefa, clicar no texto marca como concluída (risca), botão de remover cada tarefa, e um contador de quantas tarefas ainda estão pendentes. Pratiquei trabalhar com array de tarefas e criar os elementos da lista dinamicamente pelo JS, em vez de já vir pronto no HTML.

## Imagens
Não usei, o foco era manipulação de array e do DOM.

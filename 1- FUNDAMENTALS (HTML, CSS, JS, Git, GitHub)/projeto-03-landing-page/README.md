# Projeto 03 - Landing Page

## Ideia
Criar a landing page de um app fictício (TaskFlow), focando em CSS Grid e responsividade.

## O que foi feito
Montei seções (hero, funcionalidades, planos, depoimentos) usando CSS Grid pra organizar o layout em colunas, com um grid responsivo que se ajusta sozinho ao tamanho da tela. Também usei media queries em dois pontos de quebra pra reorganizar o conteúdo em telas menores.

## Imagens
Uma ilustração no hero e ícones simples pra cada funcionalidade e depoimento, só pra apoiar o layout sem tirar o foco da estrutura.

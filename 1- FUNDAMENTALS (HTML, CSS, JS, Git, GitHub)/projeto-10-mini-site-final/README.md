# Projeto 10 - Mini Site Final

## Ideia
Projeto final juntando tudo que pratiquei nos projetos anteriores, um mini site pessoal com várias páginas.

## O que foi feito
Site com 3 páginas (Início, Projetos, Contato) compartilhando o mesmo CSS e o mesmo JS. A página de Projetos tem uma galeria com filtro (como o projeto 7), a página de Contato tem um formulário validado (como o projeto 6) que salva as mensagens no `localStorage` (como o projeto 8) e mostra uma frase motivacional buscada numa API (como o projeto 9). O JS é único pra todas as páginas, usando `if` pra só rodar o código de cada funcionalidade na página certa.

## Imagens
Avatar de perfil, ícones representando HTML/CSS/JS na seção de habilidades, e miniaturas ilustrativas pra cada projeto listado no portfólio - tudo simples, só pra deixar o site com uma cara mais completa e visual.

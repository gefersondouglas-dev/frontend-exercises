# Projeto 09 - Consumo de API

## Ideia
Buscar dados de uma API externa pela primeira vez (um gerador de conselhos aleatórios).

## O que foi feito
Um botão que busca um conselho aleatório numa API pública usando `fetch` e `async/await`, mostra um estado de "carregando" enquanto espera a resposta, trata erro caso a busca falhe (sem internet, por exemplo), e guarda um histórico dos últimos conselhos buscados na sessão.

## Imagens
Não usei, o foco era consumir dados de fora do próprio código.

# Projeto 04 - Contador Interativo

## Ideia
Meu primeiro projeto com JavaScript de verdade, um contador interativo.

## O que foi feito
Botões de aumentar, diminuir e resetar um número na tela, com um campo pra escolher de quanto em quanto o contador anda. O número muda de cor (verde/vermelho) dependendo se o valor está positivo ou negativo. Pratiquei pegar elementos do HTML pelo JS, escutar cliques e usar condições (`if`/`else`).

# Projeto 01 - Cartão de Perfil

## Ideia
Criar um cartão de perfil/apresentação pessoal, meu primeiro contato com HTML e CSS puros.

## O que foi feito
Estruturei o HTML básico (título, foto, bio, lista de interesses, links de contato) e estilizei tudo com CSS simples - centralização, cores, bordas arredondadas e uma foto de perfil circular.

## Imagens
Usei um avatar simples só pra ter uma mídia no projeto e treinar como inserir/estilizar imagem no HTML. Dá pra trocar depois por uma foto real.
